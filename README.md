# Wandering Samurai Landing Page

A cinematic game landing page concept for a fictional samurai action-adventure game.

## Live Demo

Coming soon.

## Features

- Cinematic animated hero section
- Story section with atmospheric background
- Character cards
- Gameplay preview section
- Media and news/dispatch cards
- Pre-order call-to-action section
- Fully custom HTML and CSS

## Built With

- HTML
- CSS
- JavaScript
- GitHub Pages

## Project Purpose

This project was created as a portfolio piece to showcase front-end layout, visual design, game-themed branding, and interactive landing page design.
